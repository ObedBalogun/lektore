# Lektore

## Description

This project is a Django and Django Rest Framework-based API for an educational technology (edu-tech) application. The API facilitates various functionalities for both lecturers and students, including user registration, course creation and enrollment, virtual classes, and chat rooms.

## Features
- **User Registration**: Lecturers and students can register accounts.
- **Course Management**: Lecturers can create and manage courses, while students can enroll in courses.
- **Virtual Classes**: The API supports virtual classes for interactive learning experiences.
- **Chat Rooms**: Users can participate in chat rooms for communication and collaboration.

## Installation

1. Clone the repository:
   https://github.com/obedbalogun/lektore.git
2. Navigate to directory:
   lektore_backend 
3. Install dependencies:
   pip install -r requirements.txt

4. Perform database migrations:
   python manage.py makemigrations
   python manage.py migrate

5. Run the development server:
   python manage.py runserver
